# 表达编辑

用于起草、重写、润色与评审正文，也用于标题、摘要和图内文案。改善理解和信息推进，不鉴定作者身份，不保证通过 AI 检测器。规则是编辑线索，不是违禁词表。

## 工作方式

先看全文的读者任务和信息安排，再改句子。已有正文按用户授权控制改动幅度；新写时从材料组织内容，不为显得具体而编造事实。可提出有依据的建议，但不能把建议写成已执行的措施或作者已有立场。

沿用主文件的关键主张笔记，核对事实、作者判断、否定、范围、时间、归因、比较、优先级与不确定性。改写不默认等于摘要，独立事实、例子、反例和必要解释不能为追求短而丢失。长文允许分节编辑，但编辑前掌握全文约束，编辑后检查跨节重复、术语、指代与引用。

不同文体采用不同标准：方案突出取舍，指南保留步骤，报告尊重证据，经验文章保留真实观察与态度。中文句法建议仅用于中文；其他语言按其习惯编辑，不套用中文词表或标点规范。

## 1. 每段是否增加信息

**值得改：** 同一判断换词复述；背景与正文无关；首句复读标题；例子之后重复解释它已明显说明的意思；每节都用无信息的价值总结收尾。

**改法：** 确定本段要回答的问题，合并重复表达，保留最有用的依据与解释。读者已知的背景可省略，但独立文档仍应包含其目标读者需要的前提。

**保留：** 教学所需的分步解释、摘要概括、风险提醒及必要定义。判断重复要看它是否帮助当前读者，不按字面重合率删句。

## 2. 结构是否被模板牵着走

**值得改：** 反复套“观点—三点—升华”；章节长度刻意一致；并列分类交叉；正文、摘要、高亮和图注反复讲同一件事；重点被铺垫埋住。

**改法：** 按事实、解释、证据、限制、取舍或行动重新安排段落职责，重要或难懂的内容多展开，次要背景少写。重写任务可拆并或调序；润色任务发现需要大改时给出建议，不擅自重建整篇。标题被修改时检查目录、锚点和回指。

**保留：** 用户模板、真实分类、操作顺序、平行条款、用于横向比较的相同结构。不能为了打破三项排比删掉其中一项独立信息。

## 3. 句子主干是否清楚

**值得改：** 条件和背景层层前置；长定语压住主干；“进行／实现／推动＋抽象名词”堆叠；代词或被动句让读者找不到行动者。

**改法：** 找出已有的主体、动作和对象，把时间、条件与范围放到容易理解的位置；拆开过载长句，合并重复碎句。行动者未知时保持未知，不补造“团队”“系统”或责任人。

**保留：** 稳定术语、必要名词化、责任明确的被动句，以及法律、学术或技术语境所需的限定。不能机械删除“性”“化”“进行”或所有被字句。

## 4. 修辞是否代替了内容

**值得改：** 没有信息的宏大开头、夸张升华、抽象对比、假揭示与万能积极结尾；“这意味着—这说明—由此可见”并未增加论证；整段依靠“赋能、引领、深度、全面”等词制造重要感。

**改法：** 回到原文已有的具体事实或判断，直接表达关系。两端都有独立含义的对比要保住两端；只有气势的包装可以删。不得仅换同义词后保留同一个空泛结构。

**保留：** 真实反驳、范围排除、作者明确态度、有作用的比喻和正式措辞。“不仅……还……”列举两项不同能力时不必改；“闭环控制”等术语不因词表命中而删除。

作者的实质评价不等于套话；无法判断时保留或在评审中指出。编辑中发现原有因果或结论超过证据，不静默加强、削弱或替换立场；按任务范围核验，或在正文外说明待确认问题。

## 5. 节奏和称呼是否自然

**值得改：** 连续段落同开头同收尾；所有句子长度和停顿接近；括号、冒号或破折号反复掩盖句间关系；同一对象被轮换称为“平台、工具、方案、助手”，造成指代负担。

**改法：** 按信息重心调整句法和停顿，统一关键术语与称呼，省略能明确理解的重复成分。连接词只表达实际存在的因果、转折、同时或先后关系。

**保留：** 作者有意的修辞节奏、消歧所需的重复、正式条款和解释性标点。不要设置句长配额、随机换标点，或为了“变化”破坏顺序。

## 6. 文体与作者声音是否一致

**值得改：** 报告变成营销稿，方案变成口号，正式说明被改成闲聊；原有犹豫和批评被抹平；正文夹带“好问题”“下面我来”“希望有帮助”等对话残留。

**改法：** 参考用户同类样稿的表达方式，保留真实判断、感受与不确定性。没有样稿就遵循用途与原文，不替作者增加第一人称、经历、幽默、网语或情绪。邮件的问候、落款和演讲的互动有用途时保留。

**保留：** 原文自然的自我修正、方言或圈层表达，只要符合目标读者。样稿只提供风格，不能当作目标文档的事实来源。真实引语不通过添加口头语或改写语气来“人性化”。

## 7. 修改是否保住了含义

逐项检查改动涉及的信息，尤其是：

- “可能、据称、部分、仅、超过、计划、正在”承载的证据强度、数量边界与状态。
- 否定和排除的范围：“无法认定某人有错”不等于“某人没有错”。
- 责任主体、排序及先后关系：“参与”不等于“负责”，“同时”不等于“随后”。
- 引用和主张是否一起移动；来源是否被挂到它未支持的更大结论上。
- 标题、图注、图内数字与正文是否一致；代码、链接、公式及受保护片段是否完整。

保留原主张不代表已核验其真实性。没有新增材料时，不能靠润色补出实现细节、测量结果或亲身经历。无需改动的段落可以原样返回。

## 如何记录编辑结论

用“位置—具体问题—读者影响—改法”记录重要问题，不写“人味不足”“建议更自然”这种无法执行的评语。规则命中只提示检查；用语义保真和实际阅读改善判断是否完成，不用禁用词数量、字数下降或模型自评分证明效果。
