# 飞书文档的视觉表达与阅读引导

## 按信息选择载体

| 场景 | 优先考虑 | 设计重点 |
|---|---|---|
| 架构、组件边界、拓扑、多路径流程 | HTML 定制图示；需原生节点编辑时用画板 | 空间分组、层级、图标、带含义的连线；总览与细节分开 |
| 属性比较、方案取舍、指标明细 | 原生表格 | 同一比较维度，关键差异突出，长解释留在正文 |
| 动态状态、可切换方案、探索数据、复杂卡片布局 | HTML5 内容块 | 默认状态清楚，布局适应文档宽度，交互有明确用途 |
| 核心结论、决策、适用限制 | 原生高亮块 | 简短标签和结论，保留重要条件，证据在附近 |
| 真实界面、操作位置、外观 | 截图与局部标注 | 对应实际版本，裁切聚焦，有文字说明 |

架构图主动使用有含义的视觉分组、图标和空间关系。美观服务于识别和理解，不虚构节点、链路、状态或数据；颜色与形状保持一致的语义。

定制图示以 HTML 源稿为优先路径，平台与当前工具支持时直接嵌入；不支持时从相同内容与布局生成静态 SVG，再按目标能力插入。无需为同一图同时维护独立的 HTML 和 SVG 设计。普通表格、摘要和高亮仍用原生块。

## 画板

可以自由布局原生节点，也可按当前接口支持的格式导入 SVG 等内容。选择可编辑性与视觉效果之间合适的平衡，不要求所有图都来自 Mermaid／UML。

导入可能发生重排或特性降级，必须查看插入后的画板，而不只看本地 SVG。检查文字宽度、连线端点、标签、分组边界、字号和缩放后可读性。修改已有画板时复用实际目标，避免误替换其他内容。

## HTML 内容块

支持 HTML5 内容块的飞书工具可把本地单文件 HTML 写入文档。它适合定制图示、卡片式比较和有必要的交互；不要求有交互才能使用 HTML。具体写入语法与限制以当前工具帮助或接口文档为准，不能把 HTML 代码块、附件或普通网页链接称为已嵌入。

当前已核查的工具形式为：完整 HTML 保存为本地文件，在文档 XML 中使用 `<html5-block path="@./widget.html"/>`。HTML 的 `<head>` 显式包含：

```html
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<meta name="use-iframe" content="true">
<meta name="html-box-height-mode" content="auto">
<meta name="description" content="描述这个图示的内容与用途">
```

`auto` 适合正文自然展开；`viewport` 适合明确需要内部滚动或单屏呈现的内容。使用自适应宽度，避免根容器固定高度导致裁切。当前工具说明的 HTML 上限为 500KB，不内联大图片或大量数据；能力和限制变化时按当前说明执行。

先验证本地展示，再回读并查看文档中的实际效果。确认默认状态、窄屏、展开和切换后的布局；不能因交互区域收起或导出丢失而让核心结论消失。对需要导出或离线阅读的文档，提供静态图或文字摘要。当前环境不支持嵌入或无法验证时，说明限制并使用静态替代，不宣称已经完成嵌入。

## 高亮与摘要

多模块或较长的分析文档，应让读者先看到核心判断，再逐步阅读依据：

1. 开篇摘要或高亮块概括全局结论及关键影响。
2. 内容较重的章节以一句话说明局部结论或阅读目标。
3. 正文展开证据、因果和细节，图表呈现关系。

原生高亮块适合短段落或简短列表，复杂表格和画板放在块外。颜色少而一致，保留足够对比度；不把每段都高亮。正式模板有明确样式要求时，用其允许的摘要或引导形式。

验收时同时检查“结论是否容易找到”和“强调是否过量”，以及高亮后的结论是否仍保留范围、条件和不确定性。
