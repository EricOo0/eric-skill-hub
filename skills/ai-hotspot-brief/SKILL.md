# AI 热点图文科普

## 两种工作模式

### 模式 1：调研模式（用户给定主题）

用户给出具体主题（如"帮我调研 Jev"、"Gemini 3.8 有什么新东西"）时：

1. **多源检索**：按 `references/data-sources.md` 的策略检索，至少 3 个独立来源
2. **交叉验证**：关键数据点必须多源一致，不一致时按 `references/citation-guide.md` 处理
3. **内容提炼**：按 `references/content-framework.md` 组织内容
4. **生成输出**：SVG 图文卡片 + 配套文案

### 模式 2：选题模式（用户未给定主题）

用户只说"今天有什么 AI 热点"或类似时：

1. **扫描数据源**：按 `references/data-sources.md` 的选题扫描顺序
2. **筛选候选**：选 3-5 个信息充足、讨论度高的主题
3. **呈现候选**：每个候选附一句话说明 + 预估信息密度
4. **等待用户选择**：选定后进入调研模式

## 执行流程

### 第一步：信息采集与验证

- 用 `WebSearch` 检索，用 `WebFetch` 抓官方页面确认精确数据
- 每个数据点标注来源，来源可信度分级见 `references/citation-guide.md`
- 无法验证的数据不写入

### 第二步：内容组织

按 `references/content-framework.md` 的模块组织，核心要求：

**必须包含的深度模块**：
1. **一句话定义**：是什么，不是什么
2. **核心要点**：关键数据，每个标注来源
3. **横向对比**：和同类产品/方案/前代对比（见下方"对比要求"）
4. **FAQ 自问自答**：站在用户角度预判 3-5 个问题
5. **金句收尾**：一句可传播的总结

**对比要求（深度关键）**：
- 不只对比直接竞品，要做**跨领域联想对比**
- 示例：
  - 模型发布 → 对比同级别模型（GPT/Claude/GLM）的榜单数据
  - AI for Science → 对比 AlphaFold/Isomorphic/GPT-Rosalind 的路线差异
  - 新工具 → 对比替代方案的成本、效率、适用场景
- 对比维度：能力、成本、速度、适用场景、局限性

### 第三步：生成图文卡片

**卡片数量不固定**，根据信息密度自由决策（通常不会超过8张）：
- 信息少：3 张（封面+要点+总结）
- 信息丰富：多张（包含封面+定义+数据+对比+FAQ+金句）
- **严禁为凑数而拆分**，每张卡片必须有独立价值

**卡片尺寸**：360×480（3:4 竖版），适合小红书。

**生成方式**：直接写 SVG 代码，参考 `assets/` 下的模板风格，但不强制套用。根据内容灵活设计版式。

**配色规范**：
- 主色根据主题调性选择（科技紫 `#6C5CE7`、活力红 `#E74C3C`、信任蓝 `#3498DB`、增长绿 `#27AE60`、琥珀金 `#F39C12`）
- 背景：`#FAFBFC` 或渐变浅色
- 文字：标题 `#1A1A1A`，正文 `#333`，辅助 `#888`

### 第四步：可读性审核（必须执行）

生成每张 SVG 后，**必须检查**：

1. **文字溢出**：所有文本不得超出卡片边界（x 坐标范围 0-360，y 坐标范围 0-480）
2. **文字重叠**：相邻文本块之间留有足够间距（至少 6px）
3. **行距 > 字号**：多行文本的相邻行 y 坐标差必须 **大于** 字号。例如字号 46px，行距至少 50px（y 差 ≥ 50）。否则上下行会重叠（SVG 无自动行高）
4. **截断问题**：长文本必须手动换行，不能依赖自动换行
5. **字号适配**：正文 11-13px，数据突出 18-24px，标题 32-46px（封面大标题不超过 48px）
6. **对比色**：文字与背景对比度足够，浅色背景用深色字

**审核方法**：生成后重新 Read SVG 文件，逐块检查坐标和文本长度。发现问题立即修复。

**封面大标题特别注意**：如果标题需要换行，先确定行数和字号，反推每行 y 坐标：`行间距 = 字号 × 1.15`，第一行 y = 起始位置，后续每行 y 递增。不要凭感觉写坐标。

### 第五步：导出 PNG（交付格式）

**交付图片必须是 PNG**，SVG 只是中间产物。用脚本批量转换：

```bash
scripts/svg2png.sh <卡片目录>
```

脚本通过 headless Chrome 以 2x 缩放导出，输出 720×960 PNG（高清，适合小红书/抖音）。依赖本机 Google Chrome。

**导出后必须抽检**：至少打开封面 + 信息密度最高的一张 PNG，确认文字无重叠截断、emoji 正常、颜色与 SVG 一致。

### 第六步：生成配套文案

输出一段可直接粘贴到小红书正文的文本，包含：
- 吸引眼球的开头（1-2 句）
- 核心内容摘要（3-5 个要点）
- 互动引导
- 话题标签
- **完整参考来源列表**（带 URL）

## 输出文件

每次执行在工作目录下创建 `ai-brief-<主题>-<日期>/` 文件夹，包含：
- `01-cover.svg`、`02-*.svg`、`03-*.svg`...（SVG 源文件）
- `01-cover.png`、`02-*.png`、`03-*.png`...（**交付用图片**，720×960）
- `caption.txt`（配套文案）
- `sources.md`（参考来源清单）
- `preview.html`（预览页，方便查看全部卡片）
