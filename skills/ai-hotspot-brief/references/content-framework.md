# 内容框架：6 段式深度科普

每篇内容至少覆盖其中 4 段，按主题灵活组合。

## 模块 1：一句话定义

**目标**：让用户 3 秒知道"这是什么"。

**写法**：
- 先说"是什么"，再说"不是什么"
- 用类比降低理解门槛
- 控制在 2 句话内

**示例（Jev）**：
> Jev 是 TypeSafe AI 推出的"System One"决策模型。它不是聊天 LLM，不逐字生成回答，而是输入"当前状态 + 预定义问题"，直接输出选择、评分、概率和置信度，让程序继续执行。

## 模块 2：背景与动机

**目标**：解释"为什么现在出现"，建立必要性认知。

**写法**：
- 现有方案的痛点（太贵/太慢/不准/不够安全）
- 这个产品解决了哪个具体问题
- 100 字以内

**示例（Jev）**：
> LLM 逐字生成回答既慢又贵，但 Agent 场景里大量任务其实只需要"选 A 还是 B"的快速判断。Jev 把"决策"从"生成"中拆出来，专门优化这类高频判断场景。

## 模块 3：核心要点（数据驱动）

**目标**：用关键数据建立认知锚点。

**写法**：
- 选 3-5 个最有冲击力的数据点
- 每个数据配一句解释"这意味着什么"
- 数字用大字号、色块突出

**示例（Jev）**：
- 输入价格：$0.042 / 100 万 Token（对比 GPT-4o 约 $5）
- 响应时间：70-500ms（对比 LLM 通常数秒）
- 输出 Token：免费
- 性能：workflow benchmark 中 193.6× 更快、444.6× 更便宜

## 模块 4：横向对比

**目标**：通过对比让用户理解"强在哪、弱在哪"。

**写法**：
- 选 1-2 个对比对象（同类产品或主流方案）
- 对比维度：速度、成本、能力边界、适用场景
- 用表格呈现

**示例（Jev）**：

| 维度 | Jev | 传统 LLM (GPT-4o) |
|------|-----|-------------------|
| 输出形式 | 结构化决策 | 自然语言文本 |
| 响应速度 | 70-500ms | 数秒 |
| 成本 | $0.042/MTok，输出免费 | ~$5/MTok |
| 擅长 | 选择、判断、分类 | 生成、推理、创作 |
| 不擅长 | 需要自然语言交互的场景 | 高频快速判断 |

## 模块 5：FAQ 自问自答

**目标**：预判用户最可能问的问题，主动解答。

**写法**：
- 列 3-5 个问题，从最基本到最深入
- 每个问题用 1-2 句话回答
- 问题要真实（从评论区、社区讨论中提炼）

**示例（Jev）**：
- **Q：和传统分类模型有什么区别？**
  A：传统分类模型需要为每个任务单独训练，Jev 是通用决策模型，通过 prompt 就能适配新任务，无需训练。
- **Q：准确率够吗？**
  A：在官方 workflow benchmark 中表现优于主流 LLM，但具体准确率取决于任务类型，建议在自己的场景中 A/B 测试。
- **Q：什么时候该用 Jev，什么时候该用 LLM？**
  A：需要"选/判/分类"用 Jev，需要"写/想/生成"用 LLM。两者可以配合使用。

## 模块 6：金句收尾

**目标**：一句可传播、可转发的总结。

**写法**：
- 提炼核心价值主张
- 用对仗或对比句式
- 不超过 20 字

**示例**：
- "LLM 负责想和写，Jev 更擅长选和判。"
- "不是更快的聊天，而是更聪明的决策。"

## 卡片结构建议

通常 4 张卡片：
1. **封面**：一句话定义 + 3 个关键词标签
2. **背景+核心要点**：为什么出现 + 关键数据
3. **横向对比+FAQ**：对比表格 + 3 个问答
4. **总结+来源**：金句 + 参考来源

信息量大时可扩展到 5-6 张。
